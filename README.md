# David Pizza & Pétanque — Koh Lanta

Site vitrine du restaurant : vidéo, carte avec commande WhatsApp, pétanque, infos.
Site statique (HTML), aucune compilation : servi tel quel.

Après un changement de la carte (MENU ou IMG dans index.html), lancer `python3 tools/prerender-menu.py` pour réécrire la carte en HTML lisible par Google.
